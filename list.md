
## 1. Введение 

**Что такое связный список?**  
Это динамическая структура данных, где элементы (узлы) хранятся не в непрерывной области памяти, а связаны друг с другом с помощью указателей (ссылок). Каждый узел содержит данные и указатель на следующий (и, возможно, предыдущий) узел.

**Зачем нужны списки, если есть массивы?**  
- Массивы требуют непрерывного блока памяти — при большом размере это проблема.
<img width="1000" height="486" alt="image" src="https://github.com/user-attachments/assets/1c3ea0c4-249e-498d-b6a8-d2c4e5c14737" />
- Вставка/удаление в середине массива — O(n) из‑за сдвига элементов. В списке — O(1) после нахождения позиции.  

![image](https://github.com/user-attachments/assets/52fd5424-7f3f-432a-afe3-73993005dad9)

<img width="1200" height="354" alt="image" src="https://github.com/user-attachments/assets/7041521a-34c3-49b8-8f17-b1012d523804" />
- Размер списка можно изменять во время работы программы.

**Основные виды списков:**  
- Односвязный (только next)
- Двусвязный (next и prev)  
- Кольцевой (последний ссылается на первый)  

**Где используются:**  
- Реализация стеков, очередей, деков  
- Хеш-таблицы (метод цепочек)  
- Графы (списки смежности)  
- Планировщики задач, отмена действий (undo/redo)

## 2. Базовые понятия 

### 2.0 Работа с указателями
https://education.yandex.ru/handbook/cpp/article/references-pointers-const?ysclid=mlosjuzqw759351150#ukazateli 

### 2.1. Узел списка

```cpp
struct Node {
    int data;   // данные (могут быть любого типа)
    Node* next; // указатель на следующий узел
    Node* prev; // указатель на предыдущий (для двусвязного)
};
```

### 2.2. Создание узла

```cpp
Node* createNode(int value) {
    Node* newNode = new Node;  // выделение памяти в куче
    newNode->data = value;
    newNode->next = nullptr;
    // для двусвязного: newNode->prev = nullptr;
    return newNode;
}
```

### 2.3. Голова и хвост списка

- `head` — указатель на первый узел. Без него список недоступен.
- `tail` — указатель на последний узел (часто хранят для быстрого добавления в конец).

```cpp
Node* head = nullptr;
Node* tail = nullptr;
```

**Важно:** Работая с указателями, всегда проверяйте их на `nullptr` перед разыменованием.

## 3. Основные операции с односвязным списком

### 3.1. Добавление в начало

```cpp
void pushFront(Node*& head, int value) {
    Node* newNode = createNode(value);
    newNode->next = head;
    head = newNode;
    // если храните tail и список был пуст, обновите tail
}
```

### 3.2. Добавление в конец (без tail)

```cpp
void pushBack(Node*& head, int value) {
    Node* newNode = createNode(value);
    if (head == nullptr) {
        head = newNode;
        return;
    }
    Node* cur = head;
    while (cur->next != nullptr)
        cur = cur->next;
    cur->next = newNode;
}
```

### 3.3. Добавление после заданного узла

```cpp
void insertAfter(Node* pos, int value) {
    if (pos == nullptr) return;
    Node* newNode = createNode(value);
    newNode->next = pos->next;
    pos->next = newNode;
}
```

### 3.4. Добавление перед заданным узлом

**Проблема:** надо знать предыдущий узел.  
**Решение:** либо ищем предыдущий с начала, либо применяем трюк с копированием данных (не всегда применим, если данные большие).

```cpp
void insertBefore(Node*& head, Node* pos, int value) {
    if (pos == nullptr) return;
    if (pos == head) {
        pushFront(head, value);
        return;
    }
    Node* cur = head;
    while (cur != nullptr && cur->next != pos)
        cur = cur->next;
    if (cur == nullptr) return; // pos не найден (хотя он передан)
    Node* newNode = createNode(value);
    newNode->next = pos;
    cur->next = newNode;
}
```

### 3.5. Удаление узла по значению

```cpp
void deleteValue(Node*& head, int value) {
    if (head == nullptr) return;
    if (head->data == value) {
        Node* temp = head;
        head = head->next;
        delete temp;
        return;
    }
    Node* cur = head;
    while (cur->next != nullptr && cur->next->data != value)
        cur = cur->next;
    if (cur->next == nullptr) return; // не найдено
    Node* temp = cur->next;
    cur->next = temp->next;
    delete temp;
}
```

### 3.6. Поиск узла

```cpp
Node* find(Node* head, int value) {
    Node* cur = head;
    while (cur != nullptr) {
        if (cur->data == value) return cur;
        cur = cur->next;
    }
    return nullptr;
}
```

### 3.7. Обход и печать

```cpp
void printList(Node* head) {
    for (Node* cur = head; cur != nullptr; cur = cur->next)
        std::cout << cur->data << " ";
    std::cout << std::endl;
}
```

### 3.8. Замечания для C++

- Всегда освобождайте память после `new` с помощью `delete`.
- При изменении головы списка передавайте указатель по ссылке (`Node*&`) или возвращайте новую голову.
- Будьте внимательнее с краевыми случаями: пустой список, вставка/удаление первого/последнего элемента.

## 4. Двусвязные списки 

### 4.1. Преимущества

- Возможность двигаться в обе стороны.
- Удаление узла по указателю без поиска предыдущего (достаточно знать сам узел).
- Упрощённые вставка перед/после.

### 4.2. Пример вставки после узла

```cpp
void insertAfterDual(Node* pos, int value) {
    if (pos == nullptr) return;
    Node* newNode = createNode(value);
    newNode->next = pos->next;
    newNode->prev = pos;
    if (pos->next != nullptr)
        pos->next->prev = newNode;
    pos->next = newNode;
}
```

### 4.3. Удаление узла по указателю

```cpp
void deleteNode(Node*& head, Node* delNode) {
    if (delNode == nullptr) return;
    if (delNode == head)
        head = delNode->next;
    if (delNode->prev != nullptr)
        delNode->prev->next = delNode->next;
    if (delNode->next != nullptr)
        delNode->next->prev = delNode->prev;
    delete delNode;
}
```

**Обратите внимание:** здесь не нужно искать предыдущий — всё делается через поля `prev`/`next` самого удаляемого узла.

## 5. Кольцевые списки 

- Последний узел ссылается на первый (и для двусвязного — первый на последний).
- При обходе надо вовремя остановиться (сравнивать с головой).
- Удобны для циклических процессов (например, очередь с приоритетом, планировщик).

**Пример обхода кольцевого односвязного списка:**

```cpp
void printCircular(Node* head) {
    if (head == nullptr) return;
    Node* cur = head;
    do {
        std::cout << cur->data << " ";
        cur = cur->next;
    } while (cur != head);
}
```

## 7. Различия в других языках: Python и Go 

### 7.1. Python

- Нет указателей в явном виде, но все переменные — ссылки на объекты.
- Узел можно определить как класс:

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None
```

- Создание узла: `node = Node(5)` — память выделяется автоматически, сборщик мусора.
- Присваивание `node.next = other_node` работает как связывание ссылок.
- Удаление узла: достаточно убрать ссылки на него, и сборщик мусора освободит память (но может быть не сразу).
- Отсутствие контроля за памятью упрощает код, но может привести к неожиданным задержкам.
- Функции, модифицирующие голову, должны возвращать новую голову или использовать изменяемые контейнеры.

### 7.2. Go

- Есть указатели, но нет арифметики указателей.
- Узел — структура:

```go
type Node struct {
    data int
    next *Node
    prev *Node
}
```

- Создание: `node := &Node{data: 5}` — выделение в куче (или на стеке, если escape-анализ разрешит).
- Работа с памятью: есть сборщик мусора, но можно явно не освобождать.
- Функции, изменяющие голову, должны принимать указатель на указатель (`**Node`) или возвращать новую голову.
- В Go нет исключений, проверки на `nil` обязательны.
- Синтаксис разыменования: `(*node).next` или `node.next` (автоматически разыменовывается).

**Пример функции добавления в начало на Go:**

```go
func pushFront(head **Node, value int) {
    newNode := &Node{data: value, next: *head}
    *head = newNode
}
```

**Или с возвратом:**

```go
func pushFront(head *Node, value int) *Node {
    return &Node{data: value, next: head}
}
```

## 8. Типичные алгоритмы и приёмы 

### 8.1. Обнаружение цикла (алгоритм Флойда)

Используется два указателя: медленный (шаг 1) и быстрый (шаг 2). Если они встретятся — есть цикл.

```cpp
bool hasCycle(Node* head) {
    Node* slow = head;
    Node* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

### 8.2. Разворот односвязного списка

```cpp
Node* reverse(Node* head) {
    Node* prev = nullptr;
    Node* cur = head;
    while (cur) {
        Node* next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}
```

### 8.3. Слияние двух отсортированных списков

```cpp
Node* mergeSorted(Node* a, Node* b) {
    if (!a) return b;
    if (!b) return a;
    Node* result = nullptr;
    if (a->data <= b->data) {
        result = a;
        result->next = mergeSorted(a->next, b);
    } else {
        result = b;
        result->next = mergeSorted(a, b->next);
    }
    return result;
}
```

(Здесь используется рекурсия, можно реализовать итеративно.)

### 8.4. Копирование списка

```cpp
Node* copyList(Node* head) {
    if (!head) return nullptr;
    Node* newHead = createNode(head->data);
    Node* newCur = newHead;
    Node* cur = head->next;
    while (cur) {
        newCur->next = createNode(cur->data);
        newCur = newCur->next;
        cur = cur->next;
    }
    return newHead;
}
```

### 8.5. Удаление списка

```cpp
void deleteList(Node*& head) {
    while (head) {
        Node* temp = head;
        head = head->next;
        delete temp;
    }
}
```

## 9. Обзор заданий рабочей тетради и рекомендации 

### Задание 1 (0.75 балла) — Проверка корректности структуры

**Суть:** Найти проскоки и перескоки в односвязном списке без использования дополнительных структур хранения.   
- Проскок — указатель next ведёт на узел, который находится дальше по списку, пропуская промежуточные узлы (но без цикла).  
- Перескок — указатель next ведёт на уже посещённый узел (цикл или пересечение).  

**Подход 1:**  
- Для обнаружения циклов используйте алгоритм Флойда.  
- Для обнаружения проскоков можно попытаться пройти список и подсчитать длину, но без знания всех узлов это сложно. Возможно, потребуется модифицировать узлы, добавив флаг посещения (если разрешено). В условии запрещены только «явные структуры хранения», флаг в узле может считаться допустимым.  
- Если флаг использовать нельзя, подумайте о двух проходах: сначала развернуть список, затем восстановить — это позволит выявить пропуски? (Это сложно). Можно использовать алгоритм «черепахи и зайца» для циклов, а для проскоков — проверку, что при обходе каждый следующий узел достижим из предыдущего и что общее количество шагов до NULL равно количеству уникальных узлов (но как их подсчитать без доп. памяти?).  

### Задание 2 (0.25 балла) — Разделение списка по X

- Пройти по списку, распределяя узлы в два новых списка (меньше X и больше/равно X).  
- Не создавать новые узлы, только переставлять указатели.  
- Сохранить относительный порядок.  
- В конце головы двух списков должны быть корректны, хвосты указывать на nullptr.

### Задание 3 (0.5 балла) — Кольцевой двусвязный список

- Реализовать добавление в конец, удаление по значению, вывод.  
- Все операции через функции, ручное связывание запрещено.  
- Список всегда должен оставаться кольцевым.  
- При удалении последнего элемента обнулить head.

### Задание 4* (0.5 балла) — Двусвязный список с расширенными операциями

- Добавление в конец, вставка перед первым вхождением значения, удаление всех вхождений, подсчёт, вывод в обе стороны.  
- Функция is_palindrome: сравнение с конца и начала. Для двусвязного списка это делается двумя указателями: один с head, другой с tail, пока они не встретятся.

### Задание 5* (0.5 балла) — Сумма чисел из двух списков

- Цифры могут храниться в прямом или обратном порядке. В примере — в обратном (младший разряд в начале).  
- Сложение как в столбик с переносом.  
- Результат тоже список.

### Задание 6 (0.5 балла) — Перемещение чётных в начало

- Требуется O(n) времени и O(1) памяти.  
- Идея: создать два фиктивных узла (dummy) для чётных и нечётных, собрать цепочки, затем соединить.

### Задание 7* (0.5 балла) — Пересечение двух отсортированных списков

- Пройти по двум спискам одновременно (как в слиянии), добавляя в результат элементы, которые есть в обоих, с учётом кратности (минимум из частот).  
- Использовать dummy-узел для удобства сборки результата.
