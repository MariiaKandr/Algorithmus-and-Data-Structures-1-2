# 📚 Алгоритмы и структуры данных — 1 курс, 2 семестр

Добро пожаловать в репозиторий по дисциплине **«Алгоритмы и структуры данных»**. Здесь собраны материалы, которые мы разбираем на практических занятиях: теоретические конспекты, реализации ключевых структур и примеры кода на C++.

---

## 📖 О курсе

На втором семестре мы изучаем фундаментальные структуры данных и алгоритмы их обработки. Основной фокус — на деревьях различных видов:

- **Связные списки** — основа для многих динамических структур.
- **Деревья поиска** (BST, AVL, красно-чёрные, Splay‑деревья) и их балансировка.
- **Деревья отрезков** — для эффективных запросов на массивах.
- Анализ сложности, рекурсия, указатели и управление памятью.

Все примеры реализованы на **C++**, что позволяет наглядно увидеть работу с памятью и указателями.

## 🚀 Как пользоваться репозиторием

### 1. Просмотр материалов онлайн
Просто откройте любой `.md` файл на GitHub — содержимое отобразится с поддержкой Markdown.

### 2. Клонирование репозитория
```bash
git clone https://github.com/MariiaKandr/Algorithmus-and-Data-Structures-1-2.git
cd Algorithmus-and-Data-Structures-1-2
```

### 3. Рекомендуемый порядок изучения
1. **Начните с `list.md`** — если вы только знакомитесь с динамическими структурами.
2. **Затем `List_main.md`** — чтобы понять, зачем нужны деревья и где они применяются.
3. **Переходите к деревьям поиска** — лучше всего в такой последовательности:
   - `AVLTrees.md` (строгая балансировка, повороты)
   - `RBTrees.md` (более мягкая балансировка, цвет узлов)
   - `SplayTrees.md` (нестандартный подход с амортизацией)
4. **Изучите `SegmentTree.md`** — полезно для задач на массивах.
5. **Завершите анализом кода** из `List and trees.cpp`, чтобы увидеть, как теория превращается в код.

### 4. Работа с кодом
- Файлы `.md` содержат готовые фрагменты кода. Их можно копировать и вставлять в свои проекты.
- Файл `.cpp` можно скомпилировать любой C++ средой (g++, Visual Studio и др.):
  ```bash
  g++ "List and trees.cpp" -o list_and_trees
  ./list_and_trees
  ```
- Рекомендуется **писать свой код** по мотивам конспектов — это лучший способ закрепить материал.

### 5. Поиск и навигация
- Используйте поиск на GitHub (`Ctrl+K` или `Cmd+K`) для быстрого перехода к нужной теме.
- В каждом `.md` файле есть заголовки — они отображаются в структуре документа на GitHub.
