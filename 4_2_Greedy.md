## Часть 1. Размен монет (Coin Change)

**Задача:** Кассиру нужно выдать сдачу суммой \(S\), используя монеты определенных номиналов. Цель — обойтись **минимальным** количеством монет.

**Жадная стратегия:** Всегда давай самую крупную купюру, которую можешь дать, не превысив остаток.

**Пример:**
Сумма = 18 рублей. Монеты: 10, 5, 2, 1.

*   Шаг 1: Остаток 18. Самая большая ≤ 18 — это 10. Берем.
*   Шаг 2: Остаток 8. Самая большая — 5. Берем.
*   Шаг 3: Остаток 3. Самая большая — 2. Берем.
*   Шаг 4: Остаток 1. Самая большая — 1. Берем.
*   Итог: `[10, 5, 2, 1]` — 4 монеты. Это оптимум.

### Реализация 

Мы используем сортировку (жадность любит порядок). Так как мы проходили пирамидальную сортировку, здесь используем встроенную `std::sort` — она работает за \(O(N \log N)\), как и `heapsort`.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

/**
 * Размен монет жадным способом.
 * @param coins - доступные номиналы монет
 * @param amount - сумма сдачи
 * @return вектор использованных монет
 */
std::vector<int> coinChange(std::vector<int> coins, int amount) {
    // 1. Сортируем по убыванию (жадность хочет брать сначала крупные)
    std::sort(coins.begin(), coins.end(), std::greater<int>());

    std::vector<int> result;

    for (int coin : coins) {
        // Пока можем дать эту монету, даем
        while (amount >= coin) {
            amount -= coin;
            result.push_back(coin);
        }
    }

    return result;
}

// Пример использования
int main() {
    std::vector<int> coins = {1, 2, 5, 10};
    int sum = 18;

    std::vector<int> change = coinChange(coins, sum);

    std::cout << "Сдача: ";
    for (int c : change) std::cout << c << " ";
    std::cout << "\nКоличество монет: " << change.size() << std::endl;
    // Вывод: Сдача: 10 5 2 1
    //        Количество монет: 4
    return 0;
}
```

### Когда жадность врет (Контрпример)

Изменим номиналы на **1, 3, 4**. Сумма = **6**.

1.  **Жадность:** Берет 4 (самая большая). Остаток = 2. Берет 1. Берет 1.
    Результат: `4 + 1 + 1` = **3 монеты**.
2.  **Оптимум:** `3 + 3` = **2 монеты**.

> Жадность в задаче размена работает только для *канонических* систем (как российские монеты 1, 2, 5, 10). В общем случае это задача динамического программирования. Никогда не применяйте жадность к валюте вслепую!

## Часть 2. Задача о рюкзаке (Knapsack)

Это классическая задача, которая четко показывает, когда жадность разрешена, а когда запрещена.

### 2.1. Непрерывный рюкзак (Fractional Knapsack) — Жадность работает

**Условие:** Мы воры. Склад набит кучей сыпучих товаров: золотой песок (дорогой), серебро, крупа. Мы можем брать часть товара (отсыпать любое количество). У нас есть рюкзак вместимостью \(W\). Нужно унести максимум пользы (стоимости).

**Жадная стратегия:** Нужно оценивать товар по «удельной стоимости» (цена за килограмм).

1.  Вычисляем отношение `цена / вес` для каждого товара.
2.  Сортируем товары по убыванию этого отношения.
3.  Берем самые выгодные товары целиком, пока хватает места. Последний товар (который не влезает целиком) берем дробно — ровно столько, чтобы забить рюкзак.

**Пример:**
Вместимость: 50 кг.
*   Товар A: Вес 20, Цена 100 (Уд. цена = 5).
*   Товар B: Вес 40, Цена 120 (Уд. цена = 3).
*   Товар C: Вес 30, Цена 60 (Уд. цена = 2).

1.  Сортируем: A (5) -> B (3) -> C (2).
2.  Берем A (20 кг). Осталось места 30 кг. Стоимость = 100.
3.  Пытаемся взять B (40 кг). Места осталось 30. Берем 3/4 товара B: вес 30, цена \(120 \cdot (30/40) = 90\). Итог = 190.
4.  C не лезет.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

struct Item {
    double weight;
    double price;
};

double fractionalKnapsack(double capacity, std::vector<Item> items) {
    // Сортируем по удельной стоимости (price / weight) по убыванию
    std::sort(items.begin(), items.end(), [](const Item& a, const Item& b) {
        return (a.price / a.weight) > (b.price / b.weight);
    });

    double totalValue = 0.0;

    for (const Item& item : items) {
        if (capacity >= item.weight) {
            // Берем целиком
            capacity -= item.weight;
            totalValue += item.price;
        } else {
            // Берем дробную часть (остаток вместимости)
            totalValue += item.price * (capacity / item.weight);
            break; // Рюкзак полон
        }
    }
    return totalValue;
}

// Демонстрация
int main() {
    std::vector<Item> goods = {
        {20, 100}, // A
        {40, 120}, // B
        {30, 60}   // C
    };
    double cap = 50.0;
    std::cout << "Максимальная стоимость: " << fractionalKnapsack(cap, goods) << std::endl;
    // Вывод: 190
    return 0;
}
```

### 2.2. Дискретный рюкзак (0/1 Knapsack) — Жадность НЕ работает

**Условие:** Всё то же самое, но нельзя пилить предметы. Либо кладем целиком, либо не кладем.

**Попробуем жадность:** Те же товары A, B, C. Вместимость 50.
*   Жадность (по удельной цене): Берем A (20 кг). Остаток 30. B не лезет (вес 40). Берем C (30 кг). Итог: 100 + 60 = 160.
*   **Оптимум:** Пропускаем A. Берем B (40 кг) + остается место на C? Нет, остаток 10, C не лезет (вес 30). Итог: 120. (Меньше, чем 160).

*Но вот другой пример:*
Вместимость 10.
*   Товар X: Вес 6, Цена 12 (Уд. = 2.0).
*   Товар Y: Вес 5, Цена 9 (Уд. = 1.8).
*   Товар Z: Вес 5, Цена 9 (Уд. = 1.8).

Жадность возьмет X (6 кг), останется 4 кг — ни Y, ни Z не влезают. Итог = 12.
Оптимум (Y+Z) = 18.

> Как только предметы становятся неделимыми чаще всего жадный подход проваливается. Тут нужно **динамическое программирование**.

## Часть 3. Покрытие отрезков (Interval Scheduling)

Переходим к задаче, где жадность блестяще работает и очень легко пишется.

**Задача:** В одной аудитории хотят провести кучу лекций. Каждая заявка имеет время начала (`start`) и время окончания (`end`). Нужно выбрать **максимальное количество** непересекающихся заявок.

**Ловушка для новичка:** Какую заявку брать первой?
*   Самую короткую? Нет (она может перекрывать две другие).
*   Самую раннюю? Нет (она может длиться весь день).

**Жадная стратегия:** Нужно отсортировать все заявки по времени **окончания**. И всегда брать ту, которая заканчивается раньше всех из оставшихся и не конфликтует с уже выбранными.

*Логика:* Чем быстрее мы освободим аудиторию, тем больше времени останется на другие лекции.

**Пример:**
Заявки (start, end):
A: (1, 5)
B: (4, 6)
C: (5, 8)
D: (2, 3)
E: (3, 4)

1.  Сортируем по окончанию: D(3), E(4), A(5), B(6), C(8).
2.  Берем D (2-3). Аудитория занята до 3.
3.  Следующая E (3-4). Не пересекается (3 >= 3). Берем. Занята до 4.
4.  Следующая A (1-5). Пересекается (1 < 4). Пропускаем.
5.  Следующая B (4-6). Не пересекается. Берем. Занята до 6.
6.  C (5-8). Пересекается. Пропускаем.
Итог: выбрано 3 лекции (максимум).

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

struct Activity {
    int start;
    int end;
};

int maxActivities(std::vector<Activity> activities) {
    if (activities.empty()) return 0;

    // 1. Сортируем по времени окончания (жадный выбор!)
    std::sort(activities.begin(), activities.end(), 
              [](const Activity& a, const Activity& b) {
                  return a.end < b.end;
              });

    // 2. Первую заявку берем всегда (она заканчивается раньше всех)
    int count = 1;
    int lastEnd = activities[0].end;

    // 3. Проходим по остальным
    for (size_t i = 1; i < activities.size(); ++i) {
        if (activities[i].start >= lastEnd) {
            count++;
            lastEnd = activities[i].end;
        }
    }

    return count;
}

int main() {
    std::vector<Activity> schedule = {
        {1, 5}, {4, 6}, {5, 8}, {2, 3}, {3, 4}
    };
    std::cout << "Максимум лекций: " << maxActivities(schedule) << std::endl;
    // Вывод: 3
    return 0;
}
```

## Часть 4. Минимальное остовное дерево (Minimum Spanning Tree, MST)

**Задача:** Есть города (вершины) и стоимость прокладки дорог между ними (ребра с весом). Нужно построить сеть дорог так, чтобы все города были связаны (не было изолированных частей) и суммарная стоимость была минимальной. Лишних дорог (циклов) строить нельзя — получится дерево.

Мы рассмотрим два классических жадных алгоритма: Краскала и Прима.

### 4.1. Алгоритм Краскала (Kruskal's Algorithm)

**Идея:** Жадничаем на глобальном уровне. Высыпаем все дороги на стол, упорядочиваем от самой дешевой к самой дорогой. Идем по списку и строим дорогу, только если она соединяет два *еще не связанных* города.

**Инструмент:** Нам нужна структура, которая умеет быстро отвечать на два вопроса:
1.  Находятся ли два города уже в одной сети? (Find)
2.  Объединить две сети в одну? (Union)

Это **Система непересекающихся множеств (DSU / Union-Find)**.

**Пример (граф):**
```
Города: A, B, C, D.
Ребра:
A-B: 1
A-C: 3
B-C: 4
B-D: 2
C-D: 5
```
Сортируем ребра: (A-B: 1), (B-D: 2), (A-C: 3), (B-C: 4), (C-D: 5).
1. Берем A-B. Сети: {A,B}. Итог = 1.
2. Берем B-D. Сети: {A,B,D}. Итог = 3.
3. Берем A-C. Сети: {A,B,C,D}. Итог = 6.
4. Остальные ребра создадут циклы (города уже в одной куче), пропускаем их.

**Полный код Краскала с DSU:**
```cpp
#include <iostream>
#include <vector>
#include <algorithm>

struct Edge {
    int u, v, weight;
};

// DSU (Система непересекающихся множеств)
class DSU {
    std::vector<int> parent;
    std::vector<int> rank; // Для оптимизации (эвристика)
public:
    DSU(int n) {
        parent.resize(n);
        rank.resize(n, 0);
        for (int i = 0; i < n; ++i) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // Сжатие пути
        }
        return parent[x];
    }

    bool unionSets(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return false; // Уже в одной сети

        // Присоединяем дерево с меньшим рангом к большему
        if (rank[rootX] < rank[rootY]) {
            parent[rootX] = rootY;
        } else if (rank[rootX] > rank[rootY]) {
            parent[rootY] = rootX;
        } else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        return true; // Объединили
    }
};

int kruskalMST(std::vector<Edge>& edges, int verticesCount) {
    // 1. Жадный шаг: сортировка по весу
    std::sort(edges.begin(), edges.end(), [](const Edge& a, const Edge& b) {
        return a.weight < b.weight;
    });

    DSU dsu(verticesCount);
    int totalWeight = 0;
    int edgesTaken = 0;

    // 2. Перебор от лучшего к худшему
    for (const Edge& e : edges) {
        if (dsu.unionSets(e.u, e.v)) {
            totalWeight += e.weight;
            edgesTaken++;
            std::cout << "Берем ребро: " << e.u << "-" << e.v 
                      << " (вес " << e.weight << ")\n";
            
            if (edgesTaken == verticesCount - 1) break; // Дерево построено
        }
    }
    return totalWeight;
}

int main() {
    std::vector<Edge> edges = {
        {0, 1, 1}, // A-B
        {0, 2, 3}, // A-C
        {1, 2, 4}, // B-C
        {1, 3, 2}, // B-D
        {2, 3, 5}  // C-D
    };
    int result = kruskalMST(edges, 4);
    std::cout << "Общая стоимость (Краскал): " << result << std::endl;
    // Вывод: 6
    return 0;
}
```

### 4.2. Алгоритм Прима (Prim's Algorithm)

**Идея:** Жадничаем локально. Начинаем с одного произвольного города. На каждом шаге тянем самый дешевый кабель от уже построенной сети к еще не подключенному городу.

**Инструмент:** Здесь нужна **Очередь с приоритетом (MinHeap)**. Мы помещаем в кучу все ребра, которые «выглядывают» наружу из нашей сети.

**Пример (тот же граф):**
Начинаем с A (0). Куча: (B,1), (C,3).
1. Достаем минимум: (B,1). Тянем в B. Стоимость = 1.
   Добавляем в кучу соседей B, которых еще нет: (D,2). (C,4 — но у C уже есть более дешевое предложение 3).
2. Куча: (C,3), (D,2). Достаем минимум (D,2). Тянем в D. Стоимость = 3.
   Добавляем соседей D: (C,5).
3. Куча: (C,3), (C,5). Достаем минимум (C,3). Сеть построена.

**Полный код Прима:**
```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <climits>

int primMST(std::vector<std::vector<std::pair<int, int>>>& graph, int start) {
    int V = graph.size();
    std::vector<bool> inMST(V, false); // Посещенные вершины
    std::vector<int> minEdge(V, INT_MAX); // Минимальный вес ребра до вершины
    
    // Очередь с приоритетом (MinHeap)
    // Храним пары: (вес, вершина)
    std::priority_queue<
        std::pair<int, int>, 
        std::vector<std::pair<int, int>>, 
        std::greater<std::pair<int, int>>
    > pq;

    int totalWeight = 0;
    pq.push({0, start}); // Начинаем со стартовой вершины (вес 0)
    minEdge[start] = 0;

    while (!pq.empty()) {
        int u = pq.top().second;
        int weight = pq.top().first;
        pq.pop();

        // Если вершина уже в MST, игнорируем (устаревшая запись в куче)
        if (inMST[u]) continue;

        inMST[u] = true;
        totalWeight += weight;
        std::cout << "Подключаем вершину " << u << " с весом " << weight << std::endl;

        // Смотрим соседей текущей вершины
        for (auto& [v, w] : graph[u]) {
            if (!inMST[v] && w < minEdge[v]) {
                minEdge[v] = w;
                pq.push({w, v});
            }
        }
    }
    return totalWeight;
}

int main() {
    // Граф в виде списка смежности: graph[u] = { {v, вес}, ... }
    std::vector<std::vector<std::pair<int, int>>> graph(4);
    graph[0].push_back({1, 1}); graph[1].push_back({0, 1}); // A-B
    graph[0].push_back({2, 3}); graph[2].push_back({0, 3}); // A-C
    graph[1].push_back({2, 4}); graph[2].push_back({1, 4}); // B-C
    graph[1].push_back({3, 2}); graph[3].push_back({1, 2}); // B-D
    graph[2].push_back({3, 5}); graph[3].push_back({2, 5}); // C-D

    int result = primMST(graph, 0);
    std::cout << "Общая стоимость (Прим): " << result << std::endl;
    // Вывод: 6
    return 0;
}
```

### 4.3. Связь с Дейкстрой (Алгоритмом поиска кратчайшего пути)

В коде Прима обратите внимание на строчки `if (!inMST[v] && w < minEdge[v])`. Мы обновляем `minEdge` — минимальный вес *одного ребра*, ведущего к вершине.

В алгоритме Дейкстры логика **идентична**, но меняется смысл ключа в куче:
*   **Прим:** В куче лежит `w` (вес кабеля до города).
*   **Дейкстра:** В куче лежит `dist[u] + w` (сумма пути от старта через `u` до города).

**Код Дейкстры:**
```cpp
void dijkstra(std::vector<std::vector<std::pair<int, int>>>& graph, int start) {
    std::vector<int> dist(graph.size(), INT_MAX);
    std::priority_queue<std::pair<int, int>, std::vector<std::pair<int, int>>, std::greater<>> pq;

    dist[start] = 0;
    pq.push({0, start});

    while (!pq.empty()) {
        int u = pq.top().second;
        int d = pq.top().first;
        pq.pop();

        if (d > dist[u]) continue; // Устаревший путь

        for (auto& [v, w] : graph[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}
```
*Смотрите: ушло `inMST`, появилось `dist`, условие изменилось на суммирование пути.*
